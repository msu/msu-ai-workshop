# Lecture Demo

An agent writes a new Slidev lecture in this folder during the opener demo.

* Before you write a deck, read `LECTURES.md` and `VOICE.md` in this folder
* Write the deck to `deck.md` in this folder
* `LECTURES.md` and `VOICE.md` are copies from `../templates/agents/`. They name course files that are not here, such as `internal/`, `LECTURE-TOOLS.md` and `just` commands. Ignore those rules
* The workshop deck rules in `../AGENTS.md` do not apply to this folder
