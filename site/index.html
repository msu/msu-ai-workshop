Six Big Ideas

  1. Learn The Command Line Agentic work is local, not in a chatbot
    Summary
    • Web chatbots cannot see your files. An agent runs on your computer, reads and edits your files, and runs commands for you.
    • Most agents work best in the terminal: Terminal on a Mac, PowerShell on Windows.
    • You do not need the cryptic commands. The agent knows them. Learn the basics of directories and the file system, which takes a day or two.
    • Start with the MDN command line crash course.

    Watch from 4:32

  2. LLMs Love Text If an agent can read it, an agent can help with it
    Summary
    • LLMs read, write and diff text with little friction. PDF, Word and PowerPoint are harder for them.
    • Learn Markdown. Carson writes all of his slides in Markdown with Slidev and keeps them in Git.
    • Text in source control lets an agent compare the old and new versions of a lecture.
    • An AGENTS.md file gives an agent standing instructions. Carson gives students one that sets the agent up as a TA.

    Watch from 11:01

  3. Killer Visualizations Build the visualizations you always wanted in class
    Summary
    • Frontier models now make good interactive technical diagrams, e.g. a clickable full adder.
    • A diagram that took a week now takes minutes. You must still know the subject and what you want.
    • Gamify: the NAND game takes students from one NAND gate to an 8-bit adder. It took a couple of hours to build.

    Watch from 18:03

  4. Think Big You probably don't realize what you can do now
    Summary
    • AI moved the MTMC-16 emulator from a custom architecture to an x86-like one in about a week.
    • LLMs built the Scott CPU emulator, guided by expert knowledge of that CPU.
    • MSU runs its own models. catatui is a free command line agent for them, with single sign-on.
    • The limit is now your idea of how to teach the material, not cost.

    Watch from 23:52

  5. Automate The Grind Let agents deal with the tedium: automate, automate, automate
    Summary
    • Have the LLM write a script, not handle the data. A script turns a Canvas grade CSV into JavaScript that fills in the grade entry form, so student data never goes to the LLM.
    • Use agents for course chores: quizzes, answer keys, rubrics, schedule changes, and cross references after a reorder.
    • Give an LLM the YouTube transcript of a lecture to find stumbles, weak transitions and timing problems.

    Watch from 29:38

  6. Protect Learning AI is a tool, that tool can be used for good or for evil...
    Summary
    • Take-home work no longer measures learning. Carson gives in-person, handwritten quizzes every three weeks, with one page of handwritten notes.
    • Quizzes are the evaluation. Homework is for learning.
    • Never put student data into commercial tools such as ChatGPT or Claude (FERPA). Use the MSU-hosted tools.
    • Know the risks: prompt injection, wrong answers that look right, and agents that do things you cannot undo.

    Watch from 33:53
